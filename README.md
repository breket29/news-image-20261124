A program that sums up the world news of Tuesday, 24 November 2026 in one newspaper-style image: Nvidia reinstating Jensen Huang as CEO as its shares surge 31.5%, 24 dead in the candy-factory fire in Cikande, Banten, NATO sending an AWACS aircraft to Poland after Russian missiles landed there, and South Korea scrambling jets over an air-defence-zone alert near Ulleung Island. It validates the embedded poster PNG and writes it to /output/entry.png.

## Run it

```sh
python3 main.py
```

The poster itself is drawn by `draw_poster.py` (PIL) and embedded in `main.py` as base64.
